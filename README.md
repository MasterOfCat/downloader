# Telegram-бот для скачивания видео (TikTok + YouTube)

Готовый Telegram-бот на Python, который:
- скачивает видео по ссылке из **TikTok** и **YouTube**;
- имеет интерфейс на **русском и английском**;
- даёт **1 бесплатное скачивание** каждому пользователю;
- для следующих скачиваний запрашивает оплату в **Telegram Stars**.

---

## 1) Что нужно перед запуском

- Python **3.10+**
- `ffmpeg` (нужен `yt-dlp` для объединения аудио/видео)
- Telegram-бот токен от [@BotFather](https://t.me/BotFather)
- Включенные платежи в Telegram Stars для вашего бота

---

## 2) Установка

```bash
git clone <ваш-репозиторий>
cd downloader
python -m venv .venv
source .venv/bin/activate  # Linux/macOS
# .venv\Scripts\activate   # Windows
pip install -r requirements.txt
```

### Установка ffmpeg

- Ubuntu / Debian:
  ```bash
  sudo apt update && sudo apt install -y ffmpeg
  ```
- macOS (Homebrew):
  ```bash
  brew install ffmpeg
  ```
- Windows:
  Скачайте ffmpeg с официального сайта и добавьте в `PATH`.

---

## 3) Настройка переменных окружения

Скопируйте пример файла и заполните значения:

```bash
cp .env.example .env
```

`.env`:

```dotenv
BOT_TOKEN=your_telegram_bot_token
STARS_PRICE=50
MAX_VIDEO_SIZE_MB=49
DEFAULT_LANGUAGE=ru
```

### Значения

- `BOT_TOKEN` — токен бота от BotFather.
- `STARS_PRICE` — цена одного платного скачивания в Stars.
- `MAX_VIDEO_SIZE_MB` — лимит размера видео для отправки.
- `DEFAULT_LANGUAGE` — язык по умолчанию (`ru` или `en`).

---

## 4) Запуск

```bash
python bot.py
```

После запуска:
1. Пользователь отправляет `/start`.
2. Бот показывает приветствие, меню (FAQ/Язык/Как пользоваться) и кнопку выбора языка.
3. Первое скачивание — бесплатно.
4. Начиная со второго бот выставляет инвойс в Telegram Stars.

---


## 5) FAQ внутри бота

В боте есть встроенный FAQ (кнопка **❓ FAQ** или команда `/faq`), где пользователь может открыть разделы:
- как скачать видео;
- как проходит оплата Stars;
- ограничения по платформам/размеру;
- что хранится в базе (privacy).

Также доступна команда `/help` и кнопка **ℹ️ Как пользоваться** с краткой инструкцией.

---

## 6) Как работает оплата в Telegram Stars

- Для платного скачивания бот создаёт запрос в БД.
- Пользователь нажимает кнопку **Pay ⭐️ / Оплатить ⭐️**.
- Бот отправляет инвойс (`currency = XTR`).
- После `successful_payment` бот скачивает и отправляет видео.

---

## 7) Хранение данных

Используется SQLite файл `bot.db`:
- таблица `users`: язык и факт использования бесплатного скачивания;
- таблица `requests`: платные запросы и их статус.

---

## 8) Ограничения и важные замечания

1. Бот поддерживает только ссылки `tiktok.com`, `youtube.com`, `youtu.be`.
2. Если видео слишком большое, бот сообщает об ошибке.
3. Некоторые видео могут быть недоступны из-за региональных ограничений или авторских прав.
4. Убедитесь, что использование скачанного контента соответствует правилам платформ и законам вашей страны.

---

## 9) Быстрая проверка

1. Запустите бота.
2. Отправьте ссылку TikTok/YouTube — видео должно прийти бесплатно.
3. Отправьте вторую ссылку — бот должен предложить оплату Stars.
4. Проведите оплату — бот должен отправить видео.
